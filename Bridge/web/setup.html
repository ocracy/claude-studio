Set up notifications

Your Mac serves this over your private Netbird network. To let the phone install it as an app and receive notifications, it first has to trust the certificate your Mac created — a one-time step.

Certificate is trusted

Everything is in place. Open the secure version and you are done.

Open Claude Studio
1

Download the certificate

It lands in your Downloads folder as claude-studio.crt.

Download certificate
2

Install it on Android

Open Settings and search for certificate. Choose Install a certificate → CA certificate → Install anyway, then pick the file you just downloaded.

Android will warn that someone could monitor your network. That warning is about certificates in general; this one was generated on your own Mac and never left your machine.

3

Come back and open the secure version

This page notices by itself once the certificate is trusted.

Open the secure version
4

Install it as an app

Open the secure version, then ⚙ Settings → Install as an app. Chrome's ⋮ menu offers the same thing as Install app.

The entry has to say Install. Add to Home screen as a shortcut only drops a bookmark that reopens inside Chrome, address bar and all — and notifications do not work from a browser tab.

On an iPhone this only works in Safari: Share → Add to Home Screen. Chrome on iOS cannot install an app.
