Set up notifications

This Mac serves the page over your private network. For notifications and for installing it as a real app, the phone has to trust the certificate this Mac created — once, and then never again.

1 · Trust the certificate

Download it, then open Settings on the phone and search for certificate. On Android: Install a certificate → CA certificate → Install anyway, and pick the downloaded file. On iPhone: Profile Downloaded → Install, then General → About → Certificate Trust Settings and switch it on.

The warning about monitoring is about certificates in general. This one was generated on your own Mac and has never left it.

2

Install it as an app

In the secure version — the one the button above opens — use Chrome's ⋮ menu → Install app, or ⚙ Settings → Install as an app.

It has to say Install. Add to Home screen as a shortcut only leaves a bookmark that reopens inside Chrome, address bar and all — and notifications never work from a browser tab.

On iPhone this works only in Safari: Share → Add to Home Screen. Chrome on iOS cannot install an app.

3

Turn notifications on

Open the installed app → its menu → Notifications & settings, enable them and send the test notification. After that the phone buzzes the moment a session hands the turn back to you.
